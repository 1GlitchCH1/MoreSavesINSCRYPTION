# MoreSavesINSCRYPTION

я хочу создать мод на inscryption. Суть мода: добавляет выбор файлов сохранения. И собственно ячейки для них. А то в самой игре нету такого выбора и можно иметь только один файл сохранения. Важно чтобы когда ты выбираешь файл сохранения то он выводил окно какие были моды в момент предыдущего запуска сейва и затем даётся выбор между отмена или войти. Это система как в tModLoader позволяет не беспокоиться о том в каких сейвов какие моды. А так при выборе сейва он напоминает и предлагает решающий выбор.
