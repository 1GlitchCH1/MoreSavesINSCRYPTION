# Save Slots Mod для Inscryption

Добавляет **5 независимых слотов сохранения** и экран выбора сохранения при запуске игры, с предупреждением о несоответствии модов — как в tModLoader.

---

## Функции

| Функция | Описание |
|---|---|
| 5 слотов сохранения | Независимые файлы сохранения, переключаемые из главного меню |
| Отображение даты и числа модов | Каждый слот показывает дату последнего сохранения и количество модов |
| Предупреждение о несоответствии модов | При выборе слота с другим набором модов показывается диалог со списком добавленных/удалённых модов |
| Кнопки «Войти» / «Отмена» | Ты сам решаешь — войти в сейв или вернуться к выбору |
| Удаление слота | Кнопка ✕ удаляет сохранение слота (кроме активного) |

---

## Требования

- [BepInEx 5.4.x](https://github.com/BepInEx/BepInEx/releases)
- [InscryptionAPI](https://thunderstore.io/c/inscryption/p/API_dev/API/) (`cyantist.inscryption.api`)
- Inscryption (Steam, версия 1.10+)

## Установка

### Вариант А — из релиза (рекомендуется)

1. Скачай `SaveSlotsMod.dll` из [Releases](../../releases).
2. Помести файл в папку:
   ```
   <Inscryption>\BepInEx\plugins\SaveSlotsMod\SaveSlotsMod.dll
   ```
3. Запусти игру.

### Вариант Б — компиляция вручную

#### Предварительные требования
- .NET SDK 4.7.2 или Visual Studio 2022
- Установленные BepInEx и InscryptionAPI в игре

#### Сборка

1. Открой `SaveSlotsMod.csproj` и проверь путь `<GameFolder>`:
   ```xml
   <GameFolder>C:\Program Files (x86)\Steam\steamapps\common\Inscryption</GameFolder>
   ```
   Измени на свой путь, если нужно.

2. Собери проект:
   ```bash
   dotnet build -c Release
   ```

3. Готовый DLL будет в `bin/Release/net472/SaveSlotsMod.dll`.

4. Скопируй его в `<Inscryption>\BepInEx\plugins\SaveSlotsMod\`.

## Как пользоваться

1. **Запускаешь игру** — при нажатии «New Game» / «Continue» в главном меню появляется экран выбора слота.

2. **Выбираешь слот** — нажми «Загрузить» на нужном слоте.

3. **Если моды отличаются** — откроется диалог:
   - Зелёным — **добавленные** моды (есть сейчас, не было раньше)
   - Красным — **удалённые** моды (были раньше, нет сейчас)
   - Нажми **«Войти →»** чтобы войти в сейв несмотря на различия
   - Нажми **«Отмена»** чтобы вернуться к выбору слота

4. **Автосохранение** — каждый раз, когда игра сохраняется, мод автоматически обновляет сведения об активных модах для текущего слота.

## Файловая структура (в папке сохранений игры)

```
%AppData%/../LocalLow/Daniel Mullins Games/Inscryption/
├── SaveFile.gwsave          ← живое сохранение (читает игра)
└── SaveSlots/
    ├── active_slot.txt      ← номер активного слота (0–4)
    ├── Slot0_SaveFile.gwsave
    ├── Slot0_mods.json      ← список GUID модов для слота 0
    ├── Slot1_SaveFile.gwsave
    ├── Slot1_mods.json
    └── ...
```

Пример `Slot0_mods.json`:
```json
{
  "LastSaved": "2024-08-01T14:23:05Z",
  "ModGuids": [
    "com.saveslotsmod.inscryption",
    "cyantist.inscryption.api",
    "my.other.mod"
  ]
}
```

## Совместимость

- Совместим с **InscryptionAPI** и большинством модов, которые используют стандартные механизмы сохранения
- **Не совместим** с модами, которые полностью перезаписывают `SaveManager.SaveToFile` без вызова оригинала
- При смене слота **не трогает** файлы других модов — только `SaveFile.gwsave`

---

## Известные ограничения

- Системные шрифты (`Arial.ttf`) используются вместо фирменных шрифтов Inscryption — в будущей версии будет использоваться шрифт игры
- До 5 слотов (легко изменить через константу `MaxSlots` в `SaveSlotManager.cs`)
- Мод не управляет файлами других модов (например, отдельными JSON-сохранениями от сторонних плагинов)
